## 🛠️ Online Parsers, Decoders & Utilities
- **[CyberChef (GCHQ)](https://gchq.github.io/CyberChef/):** Decode Base64, hex, rot13, extract hashes, decompress data, carve files, and automate data transformations.
- **[RevShells.com](https://www.revshells.com/):** Reverse shell payload generator with encoders, listeners, and shell stabilization commands.
- **[JWT.io](https://jwt.io/):** Decode, verify, and inspect JSON Web Tokens.
- **[Regex101](https://regex101.com/):** Interactive regular expression tester and debugger for Python, PCRE, and JavaScript.
- **[CRLF Suite Online](https://crlf-suite.herokuapp.com/):** Reference and detection tools for CRLF injection.

---

## 🔍 Threat Intelligence & Reconnaissance Search Engines
- **[Shodan](https://www.shodan.io/):** Search engine for Internet-connected devices, industrial control systems, and open service banners.
- **[Censys](https://search.censys.io/):** Attack surface scanner providing deep visibility into internet infrastructure and TLS certs.
- **[crt.sh](https://crt.sh/):** Free Certificate Transparency log search for rapid passive subdomain enumeration.
- **[URLScan.io](https://urlscan.io/):** Free website scanner and analysis service detailing HTTP transactions and DOM snapshots.
- **[SecurityTrails](https://securitytrails.com/):** Historical DNS records, whois changes, and IP associations.
- **[AlienVault OTX](https://otx.alienvault.com/):** Open Threat Exchange providing community threat pulses and indicators of compromise (IOCs).
- **[Hunter.io](https://hunter.io/):** Find and verify professional email addresses associated with any domain.

---

## 📖 Exploits, Living off the Land & Bypasses
- **[GTFOBins](https://gtfobins.github.io/):** Curated list of Unix binaries that can be exploited for local privilege escalation, file transfer, and shells.
- **[LOLBAS Project](https://lolbas-project.github.io/):** Living Off The Land Binaries, Scripts, and Libraries for Windows.
- **[Exploit-DB](https://www.exploit-db.com/):** Definitive archive of public exploits and vulnerable software.
- **[PayloadsAllTheThings Web Guide](https://swisskyrepo.github.io/PayloadsAllTheThings/):** Web version of the famous payload repository.
- **[WADComs](https://wadcoms.github.io/):** Interactive cheat sheet for Windows and Active Directory exploitation tools and flags.

---

## 🛡️ Malware Sandboxes & File Analysis
- **[VirusTotal](https://www.virustotal.com/):** Analyze files and URLs with 70+ antivirus engines.
- **[ANY.RUN](https://any.run/):** Interactive dynamic malware analysis sandbox with live VM interaction.
- **[Hybrid Analysis](https://www.hybrid-analysis.com/):** Free malware analysis service powered by Falcon Sandbox.
- **[MalwareBazaar](https://bazaar.abuse.ch/):** Safe repository of malware samples shared by security researchers.
