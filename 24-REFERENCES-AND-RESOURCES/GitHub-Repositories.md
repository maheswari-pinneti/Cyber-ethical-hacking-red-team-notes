## 🌟 Curated Repositories by Category

### 1. Awesome Lists & Knowledge Bases
- **[Awesome-Hacking](https://github.com/Hack-with-Github/Awesome-Hacking):** Comprehensive collection of awesome hacking tools, resources, and references.
- **[Awesome-AppSec](https://github.com/paragonie/awesome-appsec):** Curated list of resources for learning about application security.
- **[Awesome-Incident-Response](https://github.com/meirwah/awesome-incident-response):** Curated list of tools and resources for incident response.
- **[Awesome-Threat-Intelligence](https://github.com/hslatman/awesome-threat-intelligence):** Threat intelligence resources and tools.

### 2. Wordlists, Payloads & Bypasses
- **[SecLists (Daniel Miessler)](https://github.com/danielmiessler/SecLists):** The ultimate collection of usernames, passwords, URLs, sensitive data patterns, and fuzzing payloads.
- **[PayloadsAllTheThings (Swisskyrepo)](https://github.com/swisskyrepo/PayloadsAllTheThings):** A guide of useful payloads and bypasses for web application testing and CTFs.
- **[FuzzDB](https://github.com/fuzzdb-project/fuzzdb):** Dictionary of attack patterns and primitives for black-box application fault injection.
- **[RobotsDisallowed](https://github.com/danielmiessler/RobotsDisallowed):** Curated list of the most common disallow directories from Alexa top domains.

### 3. Active Directory & Windows Tradecraft
- **[BloodHound](https://github.com/BloodHoundAD/BloodHound):** Graphical Active Directory trust relationship and attack path visualization.
- **[Impacket (Fortra)](https://github.com/fortra/impacket):** Python library for working with network protocols (secretsdump, psexec, wmiexec, smbclient).
- **[Mimikatz (Gentilkiwi)](https://github.com/gentilkiwi/mimikatz):** World-famous Windows credential extraction tool.
- **[PowerSploit](https://github.com/PowerShellMafia/PowerSploit):** PowerShell post-exploitation framework (PowerView, Invoke-Mimikatz).
- **[NetExec (formerly CrackMapExec)](https://github.com/Pennyw0rth/NetExec):** The ultimate network and AD post-exploitation tool.
- **[GhostPack (SpecterOps)](https://github.com/GhostPack):** Collection of security assessment C# tools (Seatbelt, Rubeus, SharpUp, SafetyKatz).

### 4. Web Application & API Security Tools
- **[sqlmap](https://github.com/sqlmapproject/sqlmap):** Automatic SQL injection and database takeover engine.
- **[ffuf](https://github.com/ffuf/ffuf):** Fast web fuzzer written in Go.
- **[Gobuster](https://github.com/OJ/gobuster):** Directory, DNS, and VHost busting tool written in Go.
- **[Feroxbuster](https://github.com/epi052/feroxbuster):** Fast, recursive content discovery tool in Rust.
- **[Kiterunner](https://github.com/assetnote/kiterunner):** Context-aware API endpoint fuzzer and content discovery tool.

### 5. Reconnaissance & OSINT Tools
- **[Amass (OWASP)](https://github.com/owasp-amass/amass):** In-depth attack surface mapping and external asset discovery.
- **[Subfinder (ProjectDiscovery)](https://github.com/projectdiscovery/subfinder):** Fast passive subdomain enumeration tool.
- **[httpx (ProjectDiscovery)](https://github.com/projectdiscovery/httpx):** Fast and multi-purpose HTTP toolkit.
- **[theHarvester](https://github.com/laramies/theHarvester):** OSINT tool for gathering emails, subdomains, hosts, and employee names.
- **[Sherlock](https://github.com/sherlock-project/sherlock):** Hunt down social media accounts by username across 300+ networks.

### 6. Command & Control (C2) & Adversary Emulation
- **[Sliver (Bishop Fox)](https://github.com/BishopFox/sliver):** General-purpose cross-platform adversary emulation / C2 framework.
- **[Mythic](https://github.com/its-a-feature/Mythic):** Highly extensible, collaborative C2 framework for modern red teaming.
- **[Havoc](https://github.com/HavocFramework/Havoc):** Modern, malleable C2 framework featuring a clean C++ and Qt interface.
- **[Atomic Red Team (Red Canary)](https://github.com/redcanaryco/atomic-red-team):** Library of simple, automated tests mapped to the MITRE ATT&CK framework.
