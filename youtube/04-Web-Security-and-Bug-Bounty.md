## 🌟 Top Channels & Creators

### 1. Rana Khalil
- **Channel Link:** [youtube.com/@RanaKhalil101](https://www.youtube.com/@RanaKhalil101)
- **Focus:** Detailed, structured walkthroughs of every single **PortSwigger Web Security Academy** lab.
- **Recommended Playlists:**
  - *SQL Injection Series:* In-depth theory, union-based, blind time-based, and out-of-band SQLi.
  - *Cross-Site Scripting (XSS) Series:* Reflected, stored, and DOM-based XSS with filter bypasses.
  - *Authentication & Access Control Vulnerabilities.*

### 2. NahamSec (Ben Sadeghipour)
- **Channel Link:** [youtube.com/@NahamSec](https://www.youtube.com/@NahamSec)
- **Focus:** Bug bounty methodologies, recon workflows, live hunting, and interviews with elite hackers.
- **Recommended Playlists:**
  - *Bug Bounty 101:* How to get started on HackerOne and Bugcrowd.
  - *Recon Methodology:* Automating subdomain discovery and asset monitoring.

### 3. STÖK (STOK Fredrik)
- **Channel Link:** [youtube.com/@STOKfredrik](https://www.youtube.com/@STOKfredrik)
- **Focus:** Web hacking lifestyle, bug bounty tips, hacker mentality, and weekly bounty updates.
- **Recommended Playlist:**
  - *Bounty Thursdays:* Weekly tips, new vulnerability discovery techniques, and tooling.

### 4. InsiderPhD (Dr. Katie Paxton-Fear)
- **Channel Link:** [youtube.com/@InsiderPhD](https://www.youtube.com/@InsiderPhD)
- **Focus:** Academic yet highly accessible tutorials on API security, mobile security, and bug bounty hunting.
- **Recommended Playlists:**
  - *API Security Testing:* Testing REST and GraphQL endpoints for authorization flaws.

### 5. LiveOverflow
- **Channel Link:** [youtube.com/@LiveOverflow](https://www.youtube.com/@LiveOverflow)
- **Focus:** Deep theoretical explanations of web vulnerabilities, browser internals, and CTF web challenges.
