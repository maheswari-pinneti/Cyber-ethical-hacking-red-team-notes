## 🌐 Official Standards & Security Frameworks
- **[MITRE ATT&CK Framework](https://attack.mitre.org/):** Curated knowledge base of adversary tactics and techniques.
- **[OWASP Foundation](https://owasp.org/):** Global community for application security, OWASP Top 10, and API Top 10.
- **[NIST Computer Security Resource Center](https://csrc.nist.gov/):** Authoritative guidelines, NIST CSF, and SP 800 series.
- **[CIS Benchmarks](https://www.cisecurity.org/cis-benchmarks):** Industry-standard hardening checklists for OS, servers, and cloud.
- **[CVE Program (MITRE)](https://cve.mitre.org/):** Dictionary of publicly disclosed cybersecurity vulnerabilities.
- **[NVD (National Vulnerability Database)](https://nvd.nist.gov/):** U.S. government repository of standards-based vulnerability management data.

## 💻 Essential Web Tools & Online Utilities
- **[CyberChef](https://gchq.github.io/CyberChef/):** The Swiss Army knife for decoding, hashing, encrypting, and parsing data.
- **[RevShells](https://www.revshells.com/):** Reverse shell generator with one-line payloads for Bash, Python, PowerShell, etc.
- **[GTFOBins](https://gtfobins.github.io/):** Curated list of Unix binaries that can be exploited to bypass local security restrictions.
- **[LOLBAS Project](https://lolbas-project.github.io/):** Living Off The Land Binaries, Scripts, and Libraries for Windows.
- **[PayloadsAllTheThings](https://github.com/swisskyrepo/PayloadsAllTheThings):** A guide of useful payloads and bypasses for web app pentesting.
- **[Shodan](https://www.shodan.io/):** Search engine for Internet-connected devices, servers, and open ports.
- **[Censys](https://search.censys.io/):** Attack surface intelligence search engine for discovering hosts and certificates.
- **[crt.sh](https://crt.sh/):** Certificate Search engine for passive subdomain enumeration via Certificate Transparency logs.
- **[VirusTotal](https://www.virustotal.com/):** Free online service analyzing suspicious files and URLs to detect malware types.
- **[Any.Run](https://any.run/):** Interactive online malware sandbox for dynamic analysis.

## 🛠️ Top GitHub Repositories for Hackers & Red Teamers
- **[SecLists](https://github.com/danielmiessler/SecLists):** The security tester's companion (wordlists for passwords, usernames, URLs, fuzzing).
- **[PayloadsAllTheThings](https://github.com/swisskyrepo/PayloadsAllTheThings):** Comprehensive collection of web exploitation techniques.
- **[BloodHound](https://github.com/BloodHoundAD/BloodHound):** Active Directory domain trust relationship and attack path visualization.
- **[Impacket](https://github.com/fortra/impacket):** Collection of Python classes for working with network protocols (SMB, MSRPC, Kerberos).
- **[Mimikatz](https://github.com/gentilkiwi/mimikatz):** Windows credential extraction tool (LSASS dump, Kerberos tickets).
- **[AutoRecon](https://github.com/Tib3rius/AutoRecon):** Multi-threaded network reconnaissance tool for CTFs and exams.
- **[ffuf](https://github.com/ffuf/ffuf):** Fast web fuzzer written in Go.
- **[sqlmap](https://github.com/sqlmapproject/sqlmap):** Automatic SQL injection and database takeover tool.
- **[Sliver](https://github.com/BishopFox/sliver):** Open-source cross-platform adversary emulation / C2 framework.
- **[Atomic Red Team](https://github.com/redcanaryco/atomic-red-team):** Library of simple, open-source tests mapped to MITRE ATT&CK.

## 🎮 Practical Labs & CTF Training Platforms
- **[PortSwigger Web Security Academy](https://portswigger.net/web-security):** The definitive free web security training platform.
- **[TryHackMe](https://tryhackme.com/):** Guided hands-on cybersecurity training for beginners through intermediate.
- **[HackTheBox](https://www.hackthebox.com/):** Gamified cybersecurity upskilling platform with live machines and challenges.
- **[OverTheWire Wargames](https://overthewire.org/wargames/):** Free Linux command-line and security wargames (Bandit, Natas).
- **[UnderTheWire](https://underthewire.tech/):** Free PowerShell and Windows security wargames.
- **[VulnHub](https://www.vulnhub.com/):** Downloadable vulnerable virtual machines for offline penetration testing practice.
