# Contributing to Cyber Security & Ethical Hacking Notes

Welcome to the **Cyber Security, Ethical Hacking & Red Team Notes** repository. Contributions that expand coverage, update obsolete techniques, correct inaccuracies, or add high-quality cheat sheets and writeups are warmly welcomed!

---

## Code of Conduct & Ethical Disclaimer

1. **Strictly Ethical & Educational Scope:**  
   All content in this repository is strictly for educational, defensive, authorized security testing, and research purposes. Do not submit malicious payloads intended to cause real-world harm or uncoordinated zero-day exploits.
2. **Professional & Inclusive Environment:**  
   Be respectful, constructive, and collaborative in all discussions and pull requests.

---

## How to Contribute

### 1. Adding or Updating Topic Notes
- Navigate to the appropriate numbered directory (e.g., `02-NETWORKING-FUNDAMENTALS/`, `10-WEB-APPLICATION-SECURITY/`).
- Follow the standard markdown structure:
  1. Title & Metadata
  2. Overview & Context
  3. Core Concepts & Architecture
  4. Hands-on Commands & Practical Usage
  5. Offensive & Defensive Perspectives
  6. Practical Lab Exercises
  7. References & Further Reading
- Ensure all commands and code blocks have appropriate syntax highlighting (`bash`, `python`, `powershell`, `sql`, `json`).

### 2. Adding Cheat Sheets
- Place new cheat sheets in `22-CHEAT-SHEETS/`.
- Maintain clean, tabular, copy-paste friendly format.

### 3. Adding CTF Writeups & Lab Reports
- Add CTF challenge writeups to `19-CTF-AND-PRACTICAL-LABS/08-CTF-Writeups/` using `Writeup-Template.md`.
- Add simulated lab reports to `19-CTF-AND-PRACTICAL-LABS/09-Lab-Reports/` using `Lab-Report-Template.md`.

---

## Style Guidelines
- Use standard GitHub Flavored Markdown (GFM).
- Keep file names lowercase or hyphenated as per existing convention (e.g., `01-Topic-Name.md`).
- Ensure all internal links use relative paths so they work offline and on GitHub.
